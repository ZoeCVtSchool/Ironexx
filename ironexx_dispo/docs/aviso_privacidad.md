# Aviso de Privacidad - Ironexx

**Responsable:** Ironexx, empresa dedicada a la compra-venta de maquinaria de construcción.

**Fecha de vigencia:** 11 de agosto de 2026

## 1. Datos Personales Recopilados

Para el funcionamiento del ecosistema de dispositivos inteligentes de Ironexx, se recopilan los siguientes datos personales:

### Datos del Administrador
- Nombre completo
- Correo electrónico
- Número de teléfono (para notificaciones en wearable)
- Ubicación aproximada (para funcionalidad BLE)

### Datos de Sensores (Wearable)
- Pasos dados
- Ritmo cardíaco
- Calorías quemadas
- Timestamp de los datos

### Datos de Uso
- Historial de consultas de maquinaria
- Sucursales visitadas
- Interacciones con la aplicación

## 2. Finalidad del Tratamiento

Los datos personales recopilados tienen las siguientes finalidades:

- **Gestión de notificaciones:** Enviar alertas al wearable cuando un cliente solicita contacto con servicio al cliente
- **Monitoreo de actividad:** Registrar datos de sensores para supervisión del administrador
- **Mejora del servicio:** Analizar patrones de uso para optimizar la experiencia
- **Seguridad:** Validar conexiones BLE y autenticar dispositivos

## 3. Base Legal

El tratamiento de datos personales se fundamenta en:

- **LFPDPPP:** Ley Federal de Protección de Datos Personales en Posesión de los Particulares (México)
- **Consentimiento:** El usuario otorga su consentimiento explícito al instalar y utilizar las aplicaciones
- **Finalidad legítima:** Los datos son necesarios para la prestación del servicio contratado

## 4. Derechos ARCO

El titular de los datos tiene los siguientes derechos:

- **Acceso:** Solicitar información sobre qué datos personales tenemos sobre usted
- **Rectificación:** Corregir datos inexactos o incompletos
- **Cancelación:** Solicitar la eliminación de sus datos personales
- **Oposición:** Oponerse al uso de sus datos para fines específicos

## 5. Ejercicio de Derechos ARCO

Para ejercer sus derechos ARCO, el titular deberá:

1. Enviar una solicitud por escrito al correo: privacidad@ironexx.com
2. Incluir:
   - Nombre completo
   - Domicilio
   - Correo electrónico
   - Derecho ARCO que desea ejercer
   - Descripción clara de los datos sobre los que desea ejercer el derecho
3. Adjuntar copia de identificación oficial

Ironexx responderá en un plazo máximo de 20 días hábiles.

## 6. Transferencia de Datos

No se realizan transferencias de datos personales a terceros, salvo:

- Proveedores de servicios necesarios para el funcionamiento del ecosistema (bajo contrato de confidencialidad)
- Autoridades competentes cuando sea requerido por ley

## 7. Seguridad de los Datos

Implementamos medidas de seguridad técnicas, administrativas y físicas para proteger sus datos personales:

- Encriptación en transmisión (HTTPS, BLE)
- Validación de origin en BroadcastChannel
- Content Security Policy en PWA
- Autenticación de dispositivos BLE
- Control de acceso a la información

## 8. Retención de Datos

Los datos personales se conservarán por un periodo de **30 días** a partir de su recopilación. Transcurrido este periodo, se eliminarán automáticamente de:

- LocalStorage/IndexedDB (PWA)
- Base de datos local (móvil)
- Memoria del dispositivo (wearable)

## 9. Cambios al Aviso

Cualquier modificación a este aviso será notificada a través de:
- Actualización en la aplicación móvil
- Correo electrónico a los usuarios registrados
- Publicación en el sitio web de Ironexx
